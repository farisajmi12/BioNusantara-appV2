# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-28

### Added
- Membuat struktur dasar proyek berbasis Laravel.
- Menambahkan konfigurasi awal aplikasi dan dependensi menggunakan Composer.
- Menambahkan frontend berbasis React dengan Inertia.js.
- Menambahkan konfigurasi Vite untuk proses pengembangan frontend.
- Menambahkan direktori `ai_engine` untuk kebutuhan pengembangan mesin AI.
- Menambahkan struktur direktori `app`, `bootstrap`, `config`, `database`, `public`, `resources`, `routes`, `storage`, dan `tests`.
- Menambahkan konfigurasi ESLint, Prettier, dan TypeScript.
- Menambahkan file `CONTRIBUTING.md` sebagai panduan kontribusi pengembangan proyek.

### Notes
- Ini merupakan catatan rilis awal proyek.
- Fitur yang dicantumkan merupakan komponen dasar berdasarkan struktur repositori.
- Tanggal 2026-10-28 digunakan sebagai tanggal pencatatan awal dan perlu disesuaikan jika berbeda dengan tanggal pembuatan repositori yang sebenarnya.
